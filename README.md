# Memo Terrain

Petite appli pour noter vite une idée sur le terrain (note, photo, message vocal) et l'envoyer par mail.

- Les adresses se règlent dans l'appli (page Réglages) et restent uniquement sur le téléphone.
- Aucune note, photo ou vocal n'est stocké en ligne : tout part par l'appli mail du téléphone.
